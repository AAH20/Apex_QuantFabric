# Contributing

Run `make test` and a new `make demo` population before proposing a change. Include reproduction commands and evidence limits. New semantics require a new versioned profile; do not silently change the frozen contract.

Contributions use Apache-2.0 and should include a Developer Certificate of Origin sign-off confirming submission rights. DCO is not copyright assignment or permission to relicense somebody else's code. Disclose upstream sources and dependencies. Do not copy AGPL portfolio code into this repository without an explicitly reviewed compatible plan.

Do not submit customer strategies, credentials, private feeds, employer-restricted source or unverifiable hardware claims. Public benchmarks must preserve full populations and declared measurement boundaries. Fault variants are test controls and must remain clearly identified.
