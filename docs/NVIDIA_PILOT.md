# Technical pilot proposal — not sent

## Buyer decision

Can a changed inference/runtime deployment still produce acceptable, timely financial signals while preserving exact admission rules under a frozen burst/fault population?

## Current demonstration

Native C++ kernel, separate Python oracle, synthetic bounded completions, baseline/candidate qualification, failing controls and raw replay evidence. The current model is toy arithmetic and the current timing is workstation host instrumentation. No GPU/NIC execution or customer validation is claimed.

## Proposed collaboration

Request technical review of one workload and acceptance protocol. If a shared customer need is established, conduct one bounded actual-GPU experiment, followed separately by compatible NIC/DPU work if necessary. The contribution hypothesis is application qualification and adoption evidence, not that NVIDIA lacks financial AI.

NVIDIA already publishes [financial trading infrastructure](https://www.nvidia.com/en-us/use-cases/ai-algorithmic-trading-factories/), [portfolio optimization](https://build.nvidia.com/nvidia/quantitative-portfolio-optimization) and [open low-latency inference](https://github.com/NVIDIA/dl-lowlat-infer). Evaluate reuse and the customer's incumbent harness before inventing wrappers.

NVIDIA's [GH200 inference article](https://developer.nvidia.com/blog/achieving-single-digit-microsecond-latency-inference-for-capital-markets/) and [audited STAC report](https://docs.stacresearch.com/SMC250910) describe particular inference boundaries. They do not measure this workload. [GPUNetIO](https://docs.nvidia.com/doca/sdk/gpunetio-installation-and-setup/) needs supported actual GPU/NIC arrangements; a generic GPU VM is insufficient evidence.

## Resource and agreement checklist

Freeze model/workload, CPU baseline, hardware/topology, software/firmware, operator, duration, instrumentation, numerical/decision quality, timing populations, budget and publication rights. Identify background IP and commissioned deliverables. Keep equipment access, paid integration and optional equity investment as separate transactions. No permanent device allocation or endorsement is assumed.

## Evidence required before a stronger ask

An independent reproduction, a named buyer's real change decision, sanitized representative inputs, incumbent-plus-script comparison and a bounded commercial offer. Stop or narrow if existing tooling already solves the buyer's problem adequately.

[NVIDIA Inception](https://www.nvidia.com/en-us/startups/) may be relevant for an eligible company; membership has no equity requirement but is not investment or guaranteed hardware. Check the actual business's eligibility, including its incorporation and business category.
